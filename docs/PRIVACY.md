# Privacy

OwnLedger's privacy model is architectural: the desktop application is designed not to transmit financial data. There is no account system, analytics SDK, advertising SDK, bank integration, cloud financial database, or automatic update client.

Optional project communications such as GitHub notifications or a future mailing list must remain separate from the installed application and must never receive or correlate financial data. Users remain responsible for OS security, disk encryption, physical access, and exported backups.
