# Changelog

## 1.0.0 — Public MVP
- Renamed the project from OpenBudget to OwnLedger.
- Preserved migration from OpenBudget v5 local data and legacy OpenBudget backup envelopes.
- Established offline-first privacy and community contribution rules.
- Added GitHub community, security, CI, release, issue, and dependency-management infrastructure.
- Includes the hardened budgeting, paycheck, tax-estimation, debt, goals, investments, net-worth, Decision Center, backup/restore, CSV import, and reporting baseline.

Earlier OpenBudget 2.x/3.x numbers were development-era builds and are not part of OwnLedger's public semantic-version history.
